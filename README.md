PrepAI - Fullstack (Flutter + FastAPI) project generated by assistant.
------------------------------------------------------------------
Backend:
  - Directory: backend
  - Run:
      cd backend
      pip install -r requirements.txt
      # Optionally set OPENAI_API_KEY in env before running if you want real AI replies:
      export OPENAI_API_KEY=sk-...
      uvicorn app:app --reload --host 0.0.0.0 --port 8000

Frontend:
  - Directory: frontend
  - Run:
      cd frontend
      flutter pub get
      # For Android emulator use: flutter run
      # If testing on Android emulator, API host used in code is 10.0.2.2 (maps to host machine)
      flutter run

Notes:
  - The backend will return mock AI replies unless OPENAI_API_KEY is configured.
  - Voice (speech_to_text) and TTS (flutter_tts) are implemented in frontend.
